### 탐색

규칙 1: 빈 공간을 찾는다.
규칙 2: 못 찾으면 더 큰 공간에 할당한다.

이제 빈 공간을 찾을수는 있음, 다만 여러 변수 대응 능력을 확보하기 위한 코드 작성을 해야함

아이디어 1

00의 공간만 찾기 -> 우선순위 2
01의 공간만 찾기 -> 우선순위 1
후자 공간이 안된다면 전자 공간을 할당하도록 함


### 할당

규칙 1: 찾은 공간의 마스크를 채운다
규칙 2: void * 타입으로 반환을 한다

탐색만 끝난다면 채우기 함수를 통해서 채울수가 있음


### 해제

규칙 1: 11을 지운다면 뒤에 10이 있는지 본다. 그것까지 지운다
규칙 2: 마스크를 비운다

이론은 확립이 되었음


### 확장

규칙 1: mask에는 "꽉참" 과 "하나 이상"의 값을 연속선상에 둔다
규칙 2: mask의 위치는 그 블록의 마지막으로 한다
규칙 3: mask의 위치는 레벨마다 겹치지 않는다

mask를 ptr에 내장함으로써 할게 많이 없어짐
가장 이론적인 부분임


### 중단점

탐색 부분의 보충을 실시하여야 함

값이 -1이 나오는 경우에 다시 연산을 실시해야함
