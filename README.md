### 탐색

규칙 1: 빈 공간을 찾는다.
규칙 2: 못 찾으면 더 큰 공간에 할당한다.

이제 빈 공간을 찾을수는 있음, 다만 여러 변수 대응 능력을 확보하기 위한 코드 작성을 해야함

아이디어 1

00의 공간만 찾기 -> 우선순위 2
01의 공간만 찾기 -> 우선순위 1
후자 공간이 안된다면 전자 공간을 할당하도록 함

아이디어 2

00의 공간만 찾는 것은 ``조기 분할`` 문제가 있음, 따라서 01의 공간만 찾기 로직을 강화할 필요가 있음
01의 공간을 찾을때 1레벨 이상의 경우를 전부 계산하여 적합한 공간을 찾고 할당하도록 하였음
01의 공간을 찾지 못했고 00의 공간도 찾지 못했다면 확장하고 함수를 다시 호출하도록 함


### 할당

규칙 1: 찾은 공간의 마스크를 채운다
규칙 2: void * 타입으로 반환을 한다

탐색만 끝난다면 채우기 함수를 통해서 채울수가 있음

채우는 경우의 수가 생각보다는 많았음

상향식 전달이 필요하나 


### 해제

규칙 1: 11을 지운다면 뒤에 10이 있는지 본다. 그것까지 지운다
규칙 2: 마스크를 비운다

이론은 확립이 되었음

규칙 2: mask의 위치는 그 블록의 마지막으로 한다
